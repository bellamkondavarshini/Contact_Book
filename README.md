# Contact Book 📒

A simple **command-line Contact Book application** built using Python.  
This project allows users to store, view, search, and delete contacts using a list of dictionaries.

## Features

- ✅ Add new contacts
- ✅ View all contacts
- ✅ Search contacts by name
- ✅ Delete contacts
- ✅ Simple command-line interface (CLI)

## Technologies Used

- Python 3
- Lists
- Dictionaries
- Functions
- Loops
- If-Else Conditions

## How It Works

Contacts are stored in a Python list.  
Each contact is stored as a dictionary containing:

- Name
- Phone number
- Email address

Example:

```python
{
    "name": "Rahul",
    "phone": "9876543210",
    "email": "rahul@gmail.com"
}
```

## How to Run

1. Make sure Python is installed on your computer.

2. Clone this repository:

```bash
git clone https://github.com/your-username/contact-book.git
```

3. Open the project folder:

```bash
cd contact-book
```

4. Run the program:

```bash
python contact_book.py
```

## Menu Options
